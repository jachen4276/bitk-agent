# EvidBatik —— 面向非遗知识的可溯源问答智能体

> 一个"说不出出处就拒答"的苗族蜡染知识问答智能体，以及配套的幻觉抑制评测协议。
> 参赛赛道：人工智能与智能工程（主赛道）· 自主命题
> 当前状态：**中期检查点（Day 3，2026-11-18）**

## 1. 一句话说明

给大模型 102 张丹寨苗族蜡染知识卡片，要求它回答问题时**每句话都必须指回具体卡片和原文**；指不出来就必须说"资料里没有"。本仓库要验证的是：这样做能不能显著降低编造率，代价是什么。

## 2. 为什么做这个

普通 RAG（检索增强生成）会从资料库里翻出几页让模型参考，但**翻错了页、或者翻不到，模型照样会编**。在非遗这类知识稀缺、且答案会被当作"事实"引用的领域，编造的代价很高。

本项目的核心主张只有两句：

1. **证据约束**：每条结论绑定 `(卡片ID, 原文摘录)`，绑定失败即视为无依据；
2. **显式拒答**：资料库没有记载就必须拒答，不许"合理推测"。

## 4. 怎么运行

环境：Python 3.10+，只依赖标准库，**不需要 pip install 任何东西**。

```bash
# 1) 从原始 HTML 重新生成卡片数据（可选，cards.json 已生成好）
python scripts/extract_cards.py

# 2) 跑 B3（检索直出），不需要 API，用来先验证流程
python scripts/run_baseline.py --method b3

# 3) 跑 B1（闭卷）/ B2（普通 RAG），需要 API
#    Windows PowerShell：
$env:OPENAI_API_KEY="你的key"
$env:OPENAI_BASE_URL="https://dashscope.aliyuncs.com/compatible-mode/v1"
$env:MODEL="qwen-plus"
python scripts/run_baseline.py --method b1
python scripts/run_baseline.py --method b2
```

结果写在 `results/` 下，同时生成 `.md`（人看）和 `.json`（复核/画图用）。

## 5. 三个 baseline

| 编号 | 名称 | 做什么 | 需要 API | 作用 |
| --- | --- | --- | --- | --- |
| B1 | 闭卷 | 不给资料，直接问大模型 | 是 | 下限：证明不查资料会编 |
| B2 | 普通 RAG | 检索 top-3 卡片塞进提示再答 | 是 | **主要对手**：证明"只做 RAG 不够" |
| B3 | 检索直出 | 不生成，直接贴最相关卡片的原文 | 否 | 证明"只抄原文不够，需要生成" |

补充说明：B2 的提示里已经写了"资料中没有就如实说明"，这是标准 RAG 的普遍做法。本方法要与 B2 拉开差距，靠的是**强制绑定 + 绑定失败即拒答 + 生成后证据校验**这三件事，B2 三者都没有。这个区别必须写进论文。

## 8. 已知问题（写在明处，不要藏）

1. **评测集只有 20 题**，规模不足以支撑统计结论，中期只能作为方向性证据；
2. **自动打分是启发式**，靠关键词命中，会误判，所有数字须人工复核后才能进论文；
3. **B3 事实正确率虚高**：它整段贴原文，关键词必然命中，不代表答得好；
4. **引用命中率 100% 是假象**：top-3 全引必然撞上正确卡片，应看「首引命中率」和「引用精确率」；
5. 102 张卡片中与「纹样图案/工艺原理」直接相关的只有 14 张，Agent 的覆盖范围受此限制——这既是缺陷，也是本项目"该拒答就拒答"主张的现实依据。
